# PDB Store Assets

스토어 제출용 이미지와 원본 파일을 보관한다.

## 폴더

- `screenshots/app-store/`: App Store Connect iPhone 스크린샷
- `screenshots/play-store/`: Google Play 휴대폰 스크린샷
- `promo/`: Google Play feature graphic, 홍보 이미지, 스토어용 합성 이미지
- `source/`: 편집 가능한 원본 이미지, 캡처 원본, 작업 파일

## 스크린샷 원칙

- 실제 차량 번호판은 노출하지 않는다.
- 차량 번호가 필요하면 샘플 번호만 사용한다.
- 예시 번호: `12가3456`, `123가4567`
- 카메라, 수동 입력, 통계, 주차공간, 설정, CSV 흐름을 각각 준비한다.

PDB 개인정보 처리방침

최종 업데이트: 2026-05-25

1. 앱 개요

PDB(parking db maker)는 iPhone과 Android 기기에서 차량 번호, 차종, 카테고리, 촬영일을 로컬로 관리하기 위한 주차 차량 DB 앱입니다. 앱은 서버를 사용하지 않으며, 핵심 기능은 네트워크 연결 없이 동작합니다.

2. 처리하는 정보

앱은 사용자가 직접 입력하거나 촬영 및 OCR로 생성한 다음 정보를 기기 내부에 저장할 수 있습니다.

  • 차량 번호
  • 차종
  • 차량 카테고리
  • 촬영일, 등록일, 수정일
  • 사용자가 설정에서 직접 켠 경우 OCR 실패 크롭 이미지

3. 카메라와 OCR

앱은 차량 번호판 촬영과 OCR 처리를 위해 카메라 권한을 요청합니다. OCR은 기기 내부에서 처리되며, 촬영 이미지나 OCR 결과를 외부 서버로 전송하지 않습니다.

4. 데이터 저장 위치

차량 DB와 설정 값은 사용자의 기기 내부 앱 저장 공간에 저장됩니다. 앱을 삭제하면 기기에 저장된 앱 데이터도 삭제될 수 있습니다.

5. 데이터 공유

사용자가 CSV 파일 내보내기 기능을 실행하는 경우에만 iOS 또는 Android의 시스템 공유 기능을 통해 차량 DB 파일을 외부 앱이나 저장 위치로 공유할 수 있습니다. 앱은 사용자의 선택 없이 차량 DB를 외부로 전송하지 않습니다.

6. 서버와 제3자 제공

앱은 자체 서버를 사용하지 않으며, 차량 DB나 촬영 이미지를 개발자 서버로 수집하지 않습니다. 광고 SDK나 외부 분석 SDK도 사용하지 않습니다.

7. OCR 실패 크롭 저장

OCR 실패 크롭 저장 기능은 기본적으로 꺼져 있습니다. 사용자가 설정에서 직접 켠 경우에만 OCR 개선과 현장 튜닝을 위해 실패한 번호판 크롭 이미지가 기기 내부에 저장될 수 있습니다.

8. 사용자 선택과 삭제

사용자는 앱 안에서 차량 정보를 수정하거나 CSV로 내보낼 수 있습니다. 저장된 앱 데이터를 모두 삭제하려면 앱을 삭제하거나 Android에서는 앱 저장공간을 지울 수 있습니다.

9. 문의
